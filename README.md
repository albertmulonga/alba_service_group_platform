# ALBA Service Group Platform

## Sécurité des identifiants

Les scripts de création de comptes ne contiennent plus de mots de passe par défaut. Avant d'exécuter un script dans `backend/scripts`, définissez les variables correspondantes listées dans [`backend/.env.example`](backend/.env.example) dans l'environnement du processus. Ne publiez jamais de fichier `.env` ni de mot de passe réel.
